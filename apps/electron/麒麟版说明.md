# 麒麟 ARM64 基础包

本入口复用 Markra 的编辑器与预览界面，面向银河麒麟桌面 V10 SP1 2403 ARM64。应用版本为 `2.14.9`，首个麒麟修订包为 `2.14.9-1`。原有 Tauri 入口保留。

## 构建

在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm --filter @markra/electron build
node apps/electron/scripts/package-deb.mjs
```

打包使用系统的 `unzip`、`tar` 和 `ar`，可在 macOS 或 Linux 上执行；构建环境需允许设置 `chrome-sandbox` 的 `4755` 权限。脚本从 Electron 官方发布下载固定版本的 Linux ARM64 运行时，按官方 `SHASUMS256.txt` 校验后随包交付。安装时不再下载 Electron，运行时保留沙箱和页面隔离。

已有运行时 ZIP 时，可离线打包；ZIP 同目录须有同版本官方 `SHASUMS256.txt`：

```sh
node apps/electron/scripts/package-deb.mjs \
  --runtime-zip /path/to/electron-v45.5.0-linux-arm64.zip
```

产物为 `apps/electron/build/donut-mark_2.14.9-1_arm64.deb`。包内包含编辑器、Electron、上游图标和许可证，不包含 `node_modules` 或第三方主题。

## 离线安装与使用

将安装包复制到目标麒麟电脑，在安装包所在目录执行：

```sh
sudo dpkg -i donut-mark_2.14.9-1_arm64.deb
```

随后用普通用户从应用菜单启动 **Donut Mark**，也可执行 `donut-mark /path/to/document.md`。不要用 `sudo` 启动编辑器。包使用现有系统库，不携带或替换 glibc、WebKitGTK；依赖缺失时安装会明确失败，应先核对目标系统是否符合上述版本。

本轮交付范围是实际 Markdown 文件的打开、中文编辑、预览、保存和重开，以及基础设置保存。外置主题与内网 AI 接入由后续工单完成。
