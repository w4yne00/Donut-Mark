# 麒麟 ARM64 基础包

本入口复用 Markra 的编辑器与预览界面，面向银河麒麟桌面 V10 SP1 2403 ARM64。应用版本为 `2.14.9`，首个麒麟修订包为 `2.14.9-1`。原有 Tauri 入口保留。

## 构建

在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm --filter @markra/electron build
node apps/electron/scripts/package-deb.mjs
```

打包使用系统的 `unzip`、`tar` 和 `ar`，可在 macOS 或 Linux 上执行；构建环境需允许设置 `chrome-sandbox` 的 `4755` 权限。脚本从 Electron 官方发布下载固定版本的 Linux ARM64 运行时，按官方 `SHASUMS256.txt` 校验后随包交付。安装时不再下载 Electron，运行时保留沙箱和页面隔离。

已有运行时 ZIP 时，可离线打包；ZIP 同目录须有同版本官方 `SHASUMS256.txt`：

```sh
node apps/electron/scripts/package-deb.mjs \
  --runtime-zip /path/to/electron-v45.5.0-linux-arm64.zip
```

产物为 `apps/electron/build/donut-mark_2.14.9-1_arm64.deb`。包内包含编辑器、Electron、Donut Mark 图标和许可证，不包含 `node_modules` 或第三方主题。

## 离线安装与使用

将安装包复制到目标麒麟电脑，在安装包所在目录执行：

```sh
sudo dpkg -i donut-mark_2.14.9-1_arm64.deb
```

随后用普通用户从应用菜单启动 **Donut Mark**，也可执行 `donut-mark /path/to/document.md`；再次启动时，相对路径按此次命令所在目录解析。不要用 `sudo` 启动编辑器。包使用现有系统库，不携带或替换 glibc、WebKitGTK；依赖缺失时安装会明确失败，应先核对目标系统是否符合上述版本。

本轮交付范围是实际 Markdown 文件的打开、中文编辑、预览、保存和重开，以及基础设置保存。同一文件在其他窗口或外部程序保存后，已保存的标签会自动刷新；尚未保存的编辑继续保留。文件树随授权目录变化刷新，关闭或重载窗口时释放监听。外置主题与内网 AI 接入由后续工单完成。

## 图标

彩色图标沿用[父工单已确认的造型](https://github.com/user-attachments/assets/09869bbe-319b-482b-84e3-3640bd371807)，按 Cheese Agent 的字母高度重新制作，保留 `#233B4C` 底板、雾芋紫折页 D 与右上咬口。[1024 px 母图](public/icons/donut-mark-1024.png) 的 D 高 800 px（画布的 78.125%）；字母等比缩放，保留 D 自身的宽高比。

随包提供与 Cheese Agent 相同的 16、24、32、48、64、128、256、512、1024 px 彩色图标。逐档核对可见字母高度分别为 12、18、25、37、50、100、200、400、800 px，与 Cheese Agent 一致；48 px 单独做像素对齐。全部安装到系统 `hicolor` 图标目录，桌面、启动器和任务栏按显示尺寸选用；窗口直接使用随包的 32 px 图标。

快捷菜单仍使用无底板的 `donut-mark-symbolic.svg`，保留折页内孔与咬口。其 16 px 画布内的字母高 12 px，与 Cheese Agent 单色版一致，颜色跟随菜单文字适配明暗背景。16 px 彩色图标供系统入口使用，不替代菜单单色版。外置主题不提供或替换品牌图标。

图标尺寸修订已经过资源与安装包核对；下列 UTM 记录对应本轮图标与代码修复前的包，当前候选包仍需在 #5 的正常麒麟桌面会话中复验。
