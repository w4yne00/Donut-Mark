# 麒麟 ARM64 基础包

本入口复用 Markra 的编辑器与预览界面，面向银河麒麟桌面 V10 SP1 2403 ARM64。应用版本为 `2.14.9`，首个麒麟修订包为 `2.14.9-1`。原有 Tauri 入口保留。

## 构建

在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm --filter @markra/electron build
node apps/electron/scripts/package-deb.mjs
```

打包使用系统的 `unzip`、`tar` 和 `ar`，可在 macOS 或 Linux 上执行；构建环境需允许设置 `chrome-sandbox` 的 `4755` 权限。脚本从 Electron 官方发布下载固定版本的 Linux ARM64 运行时，按官方 `SHASUMS256.txt` 校验后随包交付。安装时不再下载 Electron，运行时保留沙箱和页面隔离。

已有运行时 ZIP 时，可离线打包；ZIP 同目录须有同版本官方 `SHASUMS256.txt`：

```sh
node apps/electron/scripts/package-deb.mjs \
  --runtime-zip /path/to/electron-v45.5.0-linux-arm64.zip
```

产物为 `apps/electron/build/donut-mark_2.14.9-1_arm64.deb`。包内包含编辑器、Electron、Donut Mark 图标和许可证，不包含 `node_modules` 或第三方主题。

## 离线安装与使用

将安装包复制到目标麒麟电脑，在安装包所在目录执行：

```sh
sudo dpkg -i donut-mark_2.14.9-1_arm64.deb
```

随后用普通用户从应用菜单启动 **Donut Mark**，也可执行 `donut-mark /path/to/document.md`；再次启动时，相对路径按此次命令所在目录解析。不要用 `sudo` 启动编辑器。包使用现有系统库，不携带或替换 glibc、WebKitGTK；依赖缺失时安装会明确失败，应先核对目标系统是否符合上述版本。

同一文件在其他窗口或外部程序保存后，已保存的标签会自动刷新；尚未保存的编辑继续保留。文件树随授权目录变化刷新，关闭或重载窗口时释放监听。

在「设置 → AI 服务商」填写服务地址和模型 ID；服务需要 Bearer 鉴权时再填写 API Key。地址支持网关路径，例如 `http://model-host:8000/gateway`，保存后使用 `/gateway/v1/chat/completions`。无需模型列表。文档助手要求模型支持流式回复和工具调用；回复可随时停止，文档改动须在编辑器预览中确认。清空三项并保存即可停用。麒麟版不提供 AI 联网搜索，本地文档搜索仍可使用。

## 本地主题

在「设置 → 外观」开启「自定义主题」。浅色和深色可分别导入一个 CSS 文件，也可先选择主题文件夹，再为两种外观分别选取目录中的 CSS。

目录主题支持文件夹内不超过 1 MiB 的 UTF-8 CSS 普通文件，不跟随文件符号链接。修改原文件后点「刷新主题」即可在已打开的窗口生效。退出后重开会恢复目录和选择；换目录须重新选文件，即使文件名相同。文件缺失或无法读取时，外观页会提示，并回退到对应外观的本地导入或默认样式。

应用只读取主题源文件，不改写它们，也不加载主题引用的在线字体、图片或样式表。

## 图标

彩色图标沿用[父工单已确认的造型](https://github.com/user-attachments/assets/09869bbe-319b-482b-84e3-3640bd371807)，按 Cheese Agent 的字母高度和主笔画粗细重新制作，保留 `#233B4C` 底板、雾芋紫折页 D 与右上咬口。[1024 px 母图](public/icons/donut-mark-1024.png) 的 D 高 800 px（画布的 78.125%）；字母等比缩放，保留 D 自身的宽高比。

随包提供与 Cheese Agent 相同的 16、24、32、48、64、128、256、512、1024 px 彩色图标，由同一母图导出。各档字母高度保持画布约 78%，抗锯齿边界取样会产生至多 1 px 差异。全部安装到系统 `hicolor` 图标目录，桌面、启动器和任务栏按显示尺寸选用；窗口直接使用随包的 32 px 图标。

快捷菜单仍使用无底板的 `donut-mark-symbolic.svg`，保留折页内孔与咬口。其 16 px 画布内的字母高 12 px；主笔画从约 3.43 px 收细到 3 px，与 Cheese Agent 单色版的 3.125 px 协调，颜色跟随菜单文字适配明暗背景。16 px 彩色图标供系统入口使用，不替代菜单单色版。外置主题不提供或替换品牌图标。
